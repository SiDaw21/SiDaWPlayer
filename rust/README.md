# SiDaW Player — Rust edition (Windows)

**Готовый установщик 0.3.0:** [SiDaWPlayer-setup.exe](https://github.com/SiDaw21/SiDaWPlayer/releases/download/v0.3.0-rust/SiDaWPlayer-setup.exe) · [страница релиза](https://github.com/SiDaw21/SiDaWPlayer/releases/tag/v0.3.0-rust). Сборку каждого коммита делает GitHub Actions, бинарник проверен компиляцией на Windows-раннере.

Нативная версия плеера на Rust + egui: своя медиатека, гибкое оформление, «Моя волна» и треки из открытых каталогов. Веб-версия на JS остаётся в `../sidaw-player`.

## Возможности

- **Своя медиатека:** локальные файлы, избранное, недавние, поиск, сохранение между запусками.
- **Моя волна:** бесконечный микс по вашей коллекции; учитывает избранное и историю прослушиваний, избегает повтора текущего трека.
- **Оформление:** 5 пресетов (SiDaW Night, Aurora, Sunset, Paper, Graphite), светлый/тёмный режим, произвольный акцентный цвет RGB, масштаб интерфейса. Всё сохраняется в `state.json`.
- **Звук:** 10-полосный эквалайзер с 9 пресетами и предусилением, громкость, перемотка ±5 с.
- **Открытый каталог:** поиск аудио через [Openverse](https://openverse.org/) — агрегатор треков под свободными лицензиями (CC0, CC BY и др.) из Jamendo, Freesound и Wikimedia. В интерфейсе показываются автор, источник, лицензия и готовая строка атрибуции. API не требует ключа [2](https://agentapilist.com/agent-tools/openverse-api/).

## Что нужно для сборки на Windows

1. **Rust** — https://rustup.rs, при установке выбрать `x86_64-pc-windows-msvc`.
2. **MSVC Build Tools** — Visual Studio Build Tools с workload «Desktop development with C++» (нужен `link.exe`).
3. **Inno Setup 6** — https://jrsoftware.org/isdl.php (только для локальной сборки установщика).

## Сборка и установка

Открой **PowerShell** в папке `rust` репозитория и выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1
```

Скрипт скопирует демо-аудио из `../sidaw-player/assets/audio`, выполнит `cargo build --release` и соберёт установщик через Inno Setup. Готовый файл: `rust/installer/Output/SiDaWPlayer-setup.exe`.

Для разработки достаточно `cargo run --release` — демо-треки находятся автоматически по пути `../sidaw-player/assets/audio`.

## Где хранятся данные

- Состояние (медиатека, избранное, история прослушиваний, громкость, EQ, тема): `%APPDATA%\SiDaW\SiDaW Player\state.json`.
- Демо-треки: в папке установки, `assets\audio`.

Удаление `state.json` сбрасывает настройки к значениям по умолчанию.

## Управление

- **Все треки / Любимое / Недавние** — вкладки слева.
- **Моя волна** — включить/выключить бесконечный микс; **Открытый каталог** — поиск и воспроизведение CC-аудио; **Оформление** — темы и цвета.
- **Добавить музыку…** — нативный диалог выбора файлов (mp3, wav, flac, ogg, m4a, aac, opus — поддерживается кодеками rodio).
- **▶ / ♡ / ♥** в строке трека — воспроизведение и избранное.
- Снизу: предыдущий / play-pause / следующий, громкость, прогресс и перемотка на ±5 секунд.
- **Эквалайзер** — включение, предусиление, 10 полос и 9 пресетов; применяется к играющему звуку сразу.

## Openverse и лицензии

Приложение ищет только записи с открытыми лицензиями и показывает атрибуцию, полученную от API. Если вы используете треки из каталога в своём проекте, соблюдайте условия конкретной лицензии — строка атрибуции отображается рядом с каждым результатом. Анонимный доступ к API ограничен примерно 20 запросами в минуту [2](https://agentapilist.com/agent-tools/openverse-api/), поэтому поиск запускается только по кнопке.

## Пока не перенесено

Редактор текстов, таймер сна, мини-плеер, визуализатор, кроссфейд, подписи к трекам из коммерческих сервисов. Их можно добавить следующими шагами; для Spotify/SoundCloud нужны официальные ключи, для VK/Яндекс — лицензии, которых у сторонних приложений нет.
