# SiDaW Player — Rust edition (Windows)

Нативная версия плеера на Rust + egui. Это **первый этап порта**: локальная медиатека, воспроизведение, 10-полосный эквалайзер, избранное, поиск и сохранение состояния. Веб-версия на JS остаётся в `../sidaw-player` и пока показывает больше возможностей (радио, тексты, таймер сна, темы, стриминги) — их перенос планируется следующими шагами.

## Что нужно для сборки на Windows

1. **Rust** — https://rustup.rs, при установке выбрать `x86_64-pc-windows-msvc` (стандартный вариант для Windows).
2. **MSVC Build Tools** — Visual Studio Build Tools с workload «Desktop development with C++» (нужен компоновщик `link.exe`).
3. **Inno Setup 6** — https://jrsoftware.org/isdl.php (только для сборки установщика `.exe`).

## Сборка и установка

Открой **PowerShell** в папке `rust` этой репозитория и выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1
```

Скрипт:
1. скопирует демо-аудио из `../sidaw-player/assets/audio` в `rust/assets/audio`;
2. выполнит `cargo build --release`;
3. соберёт установщик через Inno Setup.

Готовый файл: **`rust/installer/Output/SiDaWPlayer-setup.exe`** — обычный мастер установки с ярлыками в меню «Пуск» и (по желанию) на рабочем столе. Приложение удаляется через «Параметры → Приложения» или его же мастер.

## Запуск без установки (для разработки)

```powershell
cargo run --release
```

При запуске из репозитория демо-треки находятся автоматически по пути `../sidaw-player/assets/audio` — копировать их не обязательно.

## Где хранятся данные

- Состояние (медиатека, избранное, громкость, настройки эквалайзера): `%APPDATA%\SiDaW\SiDaW Player\state.json`.
- Демо-треки: в папке установки, `assets\audio`.

Удаление `state.json` сбрасывает медиатеку и настройки к демо-состоянию.

## Управление

- **Все треки / Любимое / Недавние** — вкладки в левой панели.
- **Добавить музыку…** — нативный диалог выбора файлов; поддерживаются mp3, wav, flac, ogg, m4a, aac, opus (зависит от кодеков rodio).
- Кнопка **▶** в строке или двойной клик по названию — воспроизведение; **♡ / ♥** — избранное.
- Внизу: предыдущий / play-pause / следующий трек, громкость, прогресс и перемотка на ±5 секунд.
- Кнопка **Эквалайзер** — включение, предусиление, 10 полос и 9 пресетов. Изменения применяются к играющему треку сразу.

## Известные ограничения первого этапа

Пока не перенесены: радио-подборки, редактор текстов, таймер сна, мини-плеер, темы/акценты, визуализатор, кроссфейд и адаптеры стримингов (Spotify/SoundCloud). Код написан по зафиксированным версиям крейтов (`eframe 0.31.1`, `rodio 0.19.0`), но собран в среде разработки не был — если компилятор выдаст ошибку, пришлите её текст, исправлю точечно.
