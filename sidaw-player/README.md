# SiDaW Player

Настраиваемый музыкальный плеер: локальная медиатека, 10-полосный эквалайзер, радио, тексты песен, таймер сна, кроссфейд, мини-плеер, Drag & Drop очередь и адаптеры стриминговых источников.

## Запуск

**Веб-версия с API (рекомендуется):**
```bash
cd sidaw-player
npm run web-server
```
Откройте `http://localhost:8080`.

**Десктопное приложение (Electron):**
```bash
npm install
npm start
```

Статический `python3 -m http.server` тоже откроет интерфейс, но раздел «Источники» не заработает — ему нужен Node-сервер (`server.js`).

## Возможности

- **Звук:** 10-полосный эквалайзер (31 Гц – 16 кГц), 9 пресетов, предусиление, кроссфейд 0–12 сек, живая визуализация частот.
- **Медиатека:** списки и сетка, поиск, избранное, недавние, «часто слушаете», плейлисты, добавление файлов кнопкой и перетаскиванием. Медиатека сохраняется между перезагрузками: метаданные — в `localStorage`, добавленные аудиофайлы — в IndexedDB браузера; треки из стримингов сохраняются как ссылки на поток.
- **Радио:** подборка по текущему треку, перемешивание, умные подборки на основе истории прослушиваний.
- **Тексты песен:** встроенные демо-тексты с таймкодами, редактор своих текстов, подсветка текущей строки.
- **Очередь:** перетаскивание треков мышью, текущий и следующие треки.
- **Таймер сна:** 5/10/15/30/60 минут или пауза в конце трека.
- **Мини-плеер:** компактное окно в углу; в Electron меняется размер настоящего окна.
- **Системная интеграция:** Media Session API — управление с медиаклавиш и отображение обложки в системном плеере.
- **Оформление:** 5 тем, светлый/тёмный режим, произвольный акцентный цвет, фон (градиент или URL картинки), скругления, масштаб, плотность списка. Всё сохраняется в `localStorage`.

## Стриминговые источники — важное уточнение

Ровно так, как вы просили, приложение **не может** легально «подтянуть и воспроизвести» музыку из VK, Яндекс Музыки, Spotify и SoundCloud без официальных ключей и прав. Что реально:

| Источник | Что получилось | Почему |
|---|---|---|
| **Spotify** | Поиск по каталогу и воспроизведение 30-секундных `preview_url` | Web API отдаёт только превью; полные треки требуют Premium + Web Playback SDK |
| **SoundCloud** | Поиск и поток, если у вас уже есть `client_id` | Регистрация новых приложений в SoundCloud ограничена |
| **VK Музыка** | Честная ошибка с объяснением | Публичный audio API отключён с 2016 года |
| **Яндекс Музыка** | Честная ошибка с объяснением | Официального публичного API нет; неофициальные эндпоинты не используем такие обходы |

Подробная инструкция: [STREAMING_GUIDE.md](STREAMING_GUIDE.md) и кнопка «Как получить доступ» в интерфейсе.

Ключи вводятся в **Настройки → Источники**, хранятся только в вашем браузере и передаются на локальный `server.js`, который делает запросы к официальным API. Ни ключи, ни токены не попадают в репозиторий.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | Play / пауза |
| `←` / `→` | ±5 секунд |
| `↑` / `↓` | Громкость |
| `N` / `P` | Следующий / предыдущий трек |
| `M` | Без звука |
| `F` | В любимое |
| `Q` | Очередь |
| `L` | Текст песни |
| `E` | Эквалайзер |
| `⌘/Ctrl + K` | Поиск |

## Структура

```
index.html          разметка
styles.css          оформление и темы
themes.js           система тем и кастомизация
streams.js          карточки источников, ключи, инструкция
app.js              плеер, эквалайзер, радио, тексты, таймер, мини-плеер
server.js           локальный сервер и API-адаптеры
main.js, preload.js Electron
assets/audio        демо-треки (синтезированы локально)
assets/covers       SVG-обложки
scripts/            генератор демо-аудио
```

Демо-аудио создаётся без лицензионных ограничений:
```bash
python3 scripts/generate_demo_audio.py
```
