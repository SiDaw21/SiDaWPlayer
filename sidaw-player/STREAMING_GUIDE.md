# Как подключить музыку из стриминговых сервисов

Коротко: **`SiDaW Player` не обходит защиту сервисов и не использует неофициальные «зеркала».** Для каждого источника ниже указано, что реально доступно легально.

---

## Spotify — поиск + 30-секундные превью ✅

Web API Spotify — это каталоговый API. Он возвращает метаданные и поле `preview_url` с законным 30-секундным фрагментом. Полноценное воспроизведение песни целиком доступно только через **Web Playback SDK** и аккаунт **Premium**.

1. Войдите в [Spotify Developer Dashboard](https://developer.spotify.com/dashboard).
2. `Create app` → название, описание, redirect URI (для локальной разработки подойдёт `http://127.0.0.1:3000`).
3. Откройте настройки приложения и скопируйте **Client ID** и **Client Secret**.
4. В SiDaW Player: `Настройки → Источники → Spotify`, вставьте оба поля, `Сохранить`.
5. В поиске введите запрос и выберите вкладку Spotify. Результаты с пометкой «30 сек» можно слушать сразу.

Источники: [Spotify Web API documentation](https://developer.spotify.com/documentation/web-api), [обзор client credentials и preview_url](https://publicapis.io/spotify-api).

> Client Secret — это секрет. Не публикуйте его и не добавляйте в репозиторий. В этой версии он хранится в `localStorage` браузера и используется только локальным `server.js`.

---

## SoundCloud — только при наличии своего `client_id` ⚠️

Публичный поиск SoundCloud работает с `client_id` существующего приложения. Регистрация новых приложений в SoundCloud была остановлена и до сих пор недоступна, поэтому новый ключ получить нельзя.

1. Проверьте [SoundCloud Apps](https://soundcloud.com/you/apps) — есть ли у вас приложение с `client_id`.
2. Вставьте его в карточку SoundCloud в настройках.
3. Поиск вернёт треки; для части из них сервер попытается получить потоковый URL. Если автор закрыл доступ — трек не будет играть, и это нормально.
4. Для одиночных треков легальная альтернатива — `oEmbed` и встроенный плеер SoundCloud.

Источники: [SoundCloud API reference](https://developers.soundcloud.com/docs/api/reference), [обзор ограничений регистрации](https://rapidevelopers.com/bolt-ai-integrations/soundcloud-api).

---

## VK Музыка — официального способа нет ❌

VK [отключил публичный audio API в 2016 году](https://vk.com/dev.php?method=audio_api): методы поиска аудио и получения ссылок на MP3 доступны только сайту и официальным клиентам. Никакой токен это ограничение не снимает.

**Что делает SiDaW Player:** при выборе вкладки VK показывает понятное сообщение с этой ссылкой и не пытается обходить ограничение. Слушайте VK Музыку в официальном приложении.

---

## Яндекс Музыка — официального публичного API нет ❌

У Яндекс Музыки нет публичного API для сторонних разработчиков. Существующие неофициальные библиотеки используют внутренние эндпоинты: это нарушает условия использования и ломается без предупреждения. Проект сознательно не встраивает такие обходы.

Если у вашей организации есть договор с Яндексом — подключите его через собственный бэкенд и добавьте адаптер в `server.js`, интерфейс менять не придётся.

Источники: [обзор ситуации с API](https://musicfetch.io/services/yandex/api), [пример отказа в интеграции со ссылкой на причину](https://github.com/PixelPlayerHQ/PixelPlayer/issues/2286).

## Как добавить свой источник

В `server.js` есть объект `ADAPTERS`. Достаточно добавить одну функцию:

```js
async function searchMySource(q, creds) {
  // запрос к официальному API вашего сервиса
  return {
    ok: true,
    sourceName: 'Мой источник',
    tracks: [{ id, title, artist, album, cover, duration, streamUrl, preview: false }],
    note: 'Необязательная подпись под результатами',
  };
}
ADAPTERS.mysource = searchMySource;
```

Затем добавьте карточку в массив `SOURCES` в `streams.js` — вкладка поиска появится автоматически.

---

## Безопасность

- Ключи и токены хранятся в `localStorage` вашего браузера и передаются только на локальный `server.js`.
- Не используйте общие/публичные компьютеры для ввода Client Secret.
- Если ключ был показан где-либо публично — отзовите его в настройках сервиса и создайте новый.
